# livrslovgpt-reader

Статичний словенсько-український аудіорідер **Oksana in Ljubljana**: п'ятнадцять глав із перекладом, синхронним озвученням і мовними варіантами від A1 до C2. Глави 6–11 доступні окремо на рівнях B1 і B2, глави 12–15 — на рівнях A2 і B1.

Жива версія: https://sergiikotla.github.io/livrslovgpt-reader/

Плеєр підтримує адаптивну сторінку змісту з бейджами мовних рівнів і моделей, переходи між главами, три розміри тексту, перемикач жирності перекладу, синхронну підсвітку слів, запуск цілої фрази натисканням на будь-яке слово, повнорозмірний український переклад, перемикання сцен, автопрокрутку та швидкість відтворення. Кожна опублікована версія має власні синхронізовані текст і озвучення; глави 6–11 отримали фотореалістичні кінематографічні обкладинки.
