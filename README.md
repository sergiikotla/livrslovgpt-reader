# livrslovgpt-reader

Статичний словенсько-український аудіорідер для перших трьох глав **Loop**.

Жива версія: https://sergiikotla.github.io/livrslovgpt-reader/

Плеєр підтримує синхронну підсвітку слів, запуск цілої фрази натисканням на будь-яке слово, український переклад, перемикання сцен, автопрокрутку та швидкість відтворення.
