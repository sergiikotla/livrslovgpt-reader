# livrslovgpt-reader

Статичний словенсько-український аудіорідер **Loop**: три основні глави та сім версій четвертої глави для порівняння моделей.

Жива версія: https://sergiikotla.github.io/livrslovgpt-reader/

Плеєр підтримує адаптивну сторінку змісту з окремими бейджами моделей, переходи між главами, три розміри тексту, перемикач жирності перекладу, синхронну підсвітку слів, запуск цілої фрази натисканням на будь-яке слово, повнорозмірний український переклад, перемикання сцен, автопрокрутку та швидкість відтворення. Для кожної модельної версії четвертої глави додано окрему титульну ілюстрацію й озвучення.
